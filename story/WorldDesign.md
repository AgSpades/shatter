# 🎭 SHATTER — Aesthetic Bible (The Chitine Universe)

## Core Theme

**“Elegance built on instinct.”**

Your world should feel:

* Regal
* Ancient
* Insectile
* Oppressive
* Beautiful but unsettling

It’s a civilization pretending to be refined while standing on raw biological impulse.

Think:
🏛️ Gothic cathedral

* 🐜 Chitin armor
* 🕯️ Bioluminescent veins
* 👑 Decaying aristocracy

# 🖋️ Typography (Fonts)

You want fonts that feel:

* Regal
* Alien
* Slightly organic
* Still readable

## Primary Display Font (Titles, Logo)

**Cinzel** or **Trajan Pro** (if licensed)
Alternatives:

* Playfair Display SC
* Marcellus SC

Why:

* Roman/royal authority
* Matches aristocracy theme
* Feels ancient and law-driven

Use for:

* Game logo
* Chapter titles
* Faction names
* Palace UI

---

## Secondary UI Font (Menus, HUD, Subtitles)

**Source Serif Pro** or **Libre Baskerville**
Alternatives:

* Crimson Text
* EB Garamond

Why:

* Elegant but readable
* Literary, somber
* Fits tragic tone

Use for:

* Dialogue
* Lore text
* System menus

---

## Alien Accent Font (Optional for Hive Glyphs)

For:

* Signs
* Ritual texts
* Ancient terminals

Use a custom:

* Rune-like
* Insect-leg-stroke font

Examples to reference:

* Cthulhu-inspired glyph fonts
* Lovecraftian runes
* Hollow Knight’s fictional glyph system

These should NOT be used for readability.
Only flavor.
